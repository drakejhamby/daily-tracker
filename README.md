# Daily Tracker

A full-stack task / habit tracker.

## Features (Version 1)
- Create, read, update, and delete tasks
- Mark tasks as complete/incomplete
- Priority and category support
- Due dates
- Data saved in a JSON file

## Tech Stack
- Frontend: React + Vite (Tailwind coming soon)
- Backend: Node.js + Express
- Storage: JSON file

## How to Run

### Backend
```bash
cd backend
npm install
npm run dev

### Frontend
cd frontend
npm install
npm run dev
